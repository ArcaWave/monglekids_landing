계정 삭제 안내

아르카웨이브(Arcawave)가 제공하는 몽글키즈 앱의 계정 및 데이터 삭제 요청 방법입니다.
Account & data deletion for the Mongle Kids app by Arcawave.

방법 1 — 앱에서 직접 삭제 (즉시 처리)

  1. 몽글키즈 앱 실행 후 마을 화면 오른쪽 위 ⚙(설정)을 누릅니다.
  2. 보호자 확인(간단한 산수 문제)을 통과합니다.
  3. 설정 목록 맨 아래의 🗑️ 계정 삭제를 누릅니다.
  4. 확인 버튼을 누르면 계정과 모든 데이터가 즉시 영구 삭제됩니다.

방법 2 — 이메일로 삭제 요청

앱에 접근할 수 없는 경우, 가입하신 이메일 주소로 help@arcawave.xyz 로 "계정 삭제 요청"을 보내주세요.

본인 확인을 위해 가입 이메일 주소에서 보내주셔야 하며, 접수 후 7일 이내에 처리 결과를 회신드립니다.

삭제되는 데이터와 보관 기간

즉시 삭제 보호자 계정(이메일), 아이 프로필(닉네임·출생연도), 활동·미션 기록, 앱 설정
함께 삭제 가족 공유용 리포트 링크(공유된 웹 리포트 포함)
보관될 수 있는 것 개인을 식별할 수 없는 통계 데이터(예: 콘텐츠별 완주 수) — 개인정보가 아니며 계정과 연결되지 않습니다. 법령상 보존 의무가 있는 기록이 있는 경우 해당 법정 기간 동안만 보관 후 파기합니다.

삭제된 데이터는 복구할 수 없습니다. 구독 해지는 별도로 기기의 [설정 › Apple 계정/Google 계정 › 구독]에서 해주세요 — 계정 삭제만으로 스토어 구독이 자동 해지되지 않습니다.
